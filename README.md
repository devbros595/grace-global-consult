# Grace Global Consult Limited Website

A modern hospitality and property services platform built with Django and Bootstrap 5 for Grace Global Consult Limited. The website provides youth hostel accommodation information, property management services, cleaning solutions, office administrative support, and customer inquiry functionality through a responsive and professional user interface.

# Features

* Responsive corporate website design
* Hostel accommodation pages
* Property services showcase
* Contact and inquiry forms
* Modern UI/UX design
* Django-powered backend
* Bootstrap 5 frontend
* PostgreSQL-ready architecture
* VPS deployment ready

# Tech Stack

* Django
* Bootstrap 5
* PostgreSQL
* Gunicorn
* Nginx
* HTML5 / CSS3 / JavaScript

# Services Covered

* Youth Hostel Accommodation
* Real Estate Management
* General Cleaning Services
* Office Administrative Support

# Project Goal

To provide a scalable and professional digital platform that combines hospitality and property service operations under one unified brand experience.
